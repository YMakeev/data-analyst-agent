# Установка з нуля

Зроби це **до воркшопу**, не в день воркшопу. Більшість часу тут качається
саме, твоєї участі — хвилин десять.

Після кожного кроку є команда-перевірка. Якщо вона видала те, що написано, —
крок зроблено, йди далі.

---

## 1. Python

Потрібна версія **3.10 або новіша**.

```bash
python3 --version
```

Якщо бачиш `3.10`, `3.11`, `3.12` чи `3.13` — усе гаразд, переходь до кроку 2.

Якщо версія менша або команда не знайдена:

- **macOS** — завантаж з [python.org](https://www.python.org/downloads/)
  і постав. Або, якщо користуєшся Homebrew: `brew install python@3.12`
- **Windows** — завантаж з [python.org](https://www.python.org/downloads/).
  Під час установки **обов'язково постав галочку «Add Python to PATH»**,
  інакше команда `python` не працюватиме в терміналі
- **Linux** — `sudo apt install python3.12 python3.12-venv`

**Якщо користуєшся Anaconda:** перевір версію саме того оточення, у якому
працюватимеш (`conda activate твоє_оточення`, потім `python --version`).
Базове оточення Anaconda часто буває старим.

**Окремо для Mac на процесорі Apple (M1–M4):**

```bash
python3 -c "import platform; print(platform.machine())"
```

Має бути `arm64`. Якщо бачиш `x86_64` — у тебе стоїть Python, зібраний для
старих процесорів Intel, і частина бібліотек збиратиметься з вихідного коду
по пів години замість секунд. Постав Python з python.org і перевір ще раз.

## 4. Проєкт

```bash
git clone https://github.com/hpylieva/data-analyst-agent.git
cd data-analyst-agent
```

Створи ізольоване оточення для залежностей — щоб бібліотеки цього проєкту
не змішались з усім іншим, що є на комп'ютері:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Windows: `.venv\Scripts\activate`

Після цього на початку рядка в терміналі з'явиться `(.venv)`. Це означає, що
оточення активне. **Його треба активувати щоразу, коли відкриваєш новий
термінал** у цій папці.

```bash
pip install -e ".[dev]"
cp .env.example .env
```

Windows замість останньої команди: `copy .env.example .env`

**Перевірка:**

```bash
python -c "import mcp, psycopg, sklearn; print('залежності на місці')"
```

## 5. База даних

Обери один варіант.

### Варіант А — база від ведучої

Найпростіший: нічого не встановлюєш, дані вже є.

Відкрий файл `.env` у будь-якому редакторі й заміни рядок, що починається з
`DATABASE_URL=`, на той, який дала ведуча. Решту рядків не чіпай.

Файл `.env` починається з крапки, тому у файловому менеджері може бути
прихований. У редакторі його видно завжди: `code .env` або `nano .env`.

### Варіант Б — своя база в Docker

Твоя власна копія бази, яку не шкода зламати.

Постав [Docker Desktop](https://www.docker.com/products/docker-desktop/) і
**запусти застосунок** — він має працювати у фоні, інакше команди не
пройдуть.

```bash
docker info
```

Має видати кілька екранів тексту. Якщо бачиш `Cannot connect to the Docker
daemon` — Docker Desktop не запущений.

```bash
make setup
```

Дві-три хвилини: підніметься Postgres, згенеруються дані, натренується
ML-модель. `.env` міняти не треба, він уже налаштований на цю базу.

## 6. Фінальна перевірка

```bash
make doctor
```

Команда перевірить усе одразу й скаже, що саме не так, якщо щось не так.

Якщо `make` не знайдено — у Windows її зазвичай немає, — та сама перевірка
запускається напряму:

```bash
python scripts/doctor.py
```

Так само й решта команд: `make config-write` це
`python scripts/print_config.py --write`, `make train` це
`python ml/train.py`. Повна таблиця відповідників — у README.

## Підключення до Claude

Це ми зробимо разом на воркшопі. Якщо хочеться спробувати заздалегідь:

```bash
make config-write
```

Команда сама впише потрібне в налаштування Claude Desktop: збереже решту
твоїх налаштувань, зробить резервну копію й порахує шляхи за тебе. Шляхи
руками писати не треба — саме на них помиляються найчастіше.

Хочеш спершу подивитись, що буде додано, — `make config` просто покаже
текст, нічого не змінюючи.

Файл налаштувань лежить у теці `~/Library`, яку Finder приховує, тому
«знайти очима» його не вийде. `make config` друкує команду, яка відкриває
цю теку одразу.

Потім **повністю вийди з Claude Desktop** (`Cmd+Q` на macOS, вихід із трея на
Windows) і запусти знову. Конфігурація читається лише при старті.

Спитай у новому чаті: «що є в цій базі?». Якщо Claude перелічив сім
таблиць — усе працює.

## Якщо щось не встановлюється

Приходь усе одно — розберемось на місці, і буде запасний варіант із базою в
хмарі, для якого не потрібен ні Docker, ні налаштування.

Якщо встигаєш написати заздалегідь — напиши, підготую доступ.
